# Café Origen v0.1

Este proyecto analiza las ventas de Café Origen y muestra un reporte en pesos colombianos.

## Cómo ejecutarlo

Con Node.js instalado, abre una terminal en la carpeta que contiene este archivo y ejecuta:

```sh
node src/reporte.js
```

## Qué preguntas responde

- ¿Cuánto se vendió, cuántas unidades se vendieron, cuál fue el ticket promedio y cuánto valió la venta más alta? El resumen muestra todo el periodo y compara un día con ventas con otro sin ventas.
- ¿Cuánto se vendió en cada ciudad?
- ¿Cuántas unidades se vendieron de cada producto?
- ¿Cuáles fueron los tres productos con mayor valor total vendido?
